========================================================================
ALUR KERJA APLIKASI SIG SPASIAL (SEDERHANA)
========================================================================

1. HALAMAN UTAMA (index.php)
   - Menampilkan daftar kelompok/grup peta dari database.
   - Memiliki fitur Tambah Grup Baru dan Hapus Grup.
   - Klik "Buka Peta" untuk masuk ke halaman detail: "group.php?id=[ID_GRUP]".

2. HALAMAN PETA & ANALISIS (group.php)
   - Membuka peta utama Leaflet.js sesuai grup yang dipilih.
   - Pengguna menggambar wilayah (Polygon) & menaruh marker (Point) di peta utama.
   - Koordinat spasial tersebut langsung disimpan ke database PostgreSQL.
   - Saat memilih Wilayah A & Wilayah B di dropdown sidebar:
     * JavaScript memanggil 7 API analisis di folder 'api/'.
     * API PHP memproses relasi spasial database (ST_Union, ST_Intersection, dll).
     * Hasil akhir digambar secara otomatis pada 7 peta kecil di bawahnya.
